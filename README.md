# WT Calendrier

Calendrier communautaire non officiel pour War Thunder. Il n’est pas affilié à Gaijin Entertainment.

## Ouvrir le site
Double-cliquez sur `index.html` ou ouvrez-le dans un navigateur moderne. Aucune installation ni serveur n’est nécessaire.

## GitHub Pages
1. Créez un dépôt et placez ces fichiers à la racine de la branche `main`.
2. Dans **Settings → Pages**, choisissez **Deploy from a branch**, la branche `main` et le dossier `/ (root)`.
3. Enregistrez : GitHub Pages publiera `index.html`.

Le paramètre `?lang=fr`, `?lang=en`, `?lang=de`, `?lang=es`, `?lang=ru` ou `?lang=zh` force la langue. Le choix est ensuite mémorisé dans `localStorage`.

Les dates « habituelles » et « estimées » sont des repères communautaires, pas des annonces officielles. Compilation arrêtée au **2 octobre 2026**.
